# ETSU Campus Map

Interactive, responsive campus map for East Tennessee State University.

## Prototype goals

- Search buildings, offices, and rooms
- Click buildings for details
- Mobile-friendly campus exploration
- Real building photographs
- Walking and accessible routing
- Campus directory integration
- Future indoor/floor maps

## Stack

- React
- Vite
- Leaflet

## Development

```bash
npm install
npm run dev
```

## Deployment

The project is designed to work first on GitHub and can later be deployed to an ETSU web server or other static hosting platform.
